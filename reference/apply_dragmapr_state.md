# Apply a dragmapr state to sf geometry

Apply a dragmapr state to sf geometry

## Usage

``` r
apply_dragmapr_state(x, state, region_col)
```

## Arguments

- x:

  An `sf` object.

- state:

  A `dragmapr_state` object.

- region_col:

  Column in `x` defining draggable groups.

## Value

An `sf` object with region offsets applied.
