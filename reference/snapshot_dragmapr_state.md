# Snapshot or restore dragmapr state

Snapshot or restore dragmapr state

## Usage

``` r
snapshot_dragmapr_state(state)

restore_dragmapr_state(snapshot)
```

## Arguments

- state:

  A `dragmapr_state` object.

- snapshot:

  A list previously returned by `snapshot_dragmapr_state()`.

## Value

`snapshot_dragmapr_state()` returns a plain list.
`restore_dragmapr_state()` returns a `dragmapr_state`.
